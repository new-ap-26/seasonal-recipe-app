# 旬ごはん

旬の食材を使い、分量・手順どおりに作れば再現しやすいレシピを蓄積・改善していく個人用PWAです。

公開URL：https://new-ap-26.github.io/seasonal-recipe-app/

## 主な機能

- ホーム / レシピ集 / 旬 / 薬膳 / マイ
- 料理カテゴリ・季節・「作り置き」「定番料理」での絞り込みと、料理名・説明・材料名での検索
- 材料のグループ表示と分量区分（固定／目安／お好み）、調理キュー、コツ、旬・栄養・薬膳・保存情報
- お気に入り、わが家の定番
- 5段階評価、味タグ、自由メモ、調理履歴
- マイレシピ修正とオリジナル復元
- LocalStorage保存、JSONバックアップ / 復元
- PWA（ホーム画面に追加して利用）

## レシピデータ

- 全51品（春・夏・秋・冬 各10品、通年・定番料理 11品）
- データ：`src/data/`（`spring.ts` / `summer.ts` / `autumn.ts` / `winter.ts` / `standard.ts`）
- すべて調理テスト前（`cookingTestStatus: 'untested'`、画面上は「試作前」表示）です。実際の調理テスト→評価→調整→承認の流れで、段階的に確定させます。
- 栄養・薬膳・保存情報は、根拠を確認できたものだけを掲載します。根拠のない保存日数や数値は設定しません。
- 薬膳は伝統的な食養生の考え方として扱い、現代医学上の治療効果を示すものではありません。

## データの扱い

- 個人データ（評価・メモ・お気に入り・修正）は、利用者のブラウザのLocalStorageだけに保存し、外部へ送信しません。
- JSONバックアップには個人の記録が含まれるため、このリポジトリには置きません。
- このリポジトリは公開されています。APIキー・パスワード・個人情報・非公開資料は登録しません。

## 開発

```bash
npm ci
npm run dev
```

- 依存パッケージはバージョンを固定しています（`package.json` / `package-lock.json`）。インストールは `npm ci` を使います。
- `.npmrc` で、インストール時のスクリプト実行を無効にしています。

## 公開（GitHub Pages）

- `main` への反映で、GitHub Actions（`.github/workflows/deploy.yml`）がビルドし、GitHub Pagesへ自動デプロイします。
- 利用するActionsは、コミットハッシュで固定しています。
- 変更は作業用ブランチ→Pull Request→マージの順で反映します。
- `vite.config.ts` は、GitHub Actions上のリポジトリ名から自動的にbase pathを設定します。
